# 产品需求评审（2026 Q1）

## 背景

客服团队每个月要处理大约 400 条关于导出功能的反馈，其中一半以上是希望支持批量导出为 Excel。当前只能逐篇导出，平均每篇要多花 3 分钟。

## 目标

把「批量导出」做成一个开关式的功能，让不熟悉脚本的用户也能一次导出 50 篇以内的文档。**这一版的成功标准是：上线两周内，导出相关的客诉下降 30%。**

## 范围

- 支持按标签筛选之后批量导出
- 支持导出为 Excel 和 Markdown 两种格式
- 不支持跨笔记本导出，需要用户先切换笔记本

## 排期

开发和联调预计 10 个工作日，灰度一周。如果 6 月 20 日之前拿不到稳定的构建，就顺延到下一个迭代，不要压缩测试时间。

## 风险

批量导出会一次性读取大量文档，内存占用可能翻倍。需要在导出前做一次容量估算，超过阈值就分批处理，并且给用户进度提示。

## 待确认

- 导出文件是放在工作空间目录，还是让浏览器直接下载？
- 是否需要记录导出日志，方便排查用户的问题？
